# 附录 B：常见错误速查表

> 写代码报错太正常了——**每个程序员每天都在和报错打交道**。这本附录把全书各章最容易踩的坑汇成一张表，卡住时翻一翻，比在网上乱搜快得多。

---

## 怎么用这张表（三步定位法）

> 📝 **Note:** 报错不可怕，可怕的是"看都不看就复制去搜"。按下面三步，多数错误你自己就能解决。

1. **先读报错信息** —— 终端里那堆红字，**最后一行**通常写着真正的错误类型和位置，比如 `NameError: name 'y' is not defined`（名字 y 没定义）。
2. **定位章节** —— 看本表最左"章节"列的小节号（如 `§2.1`），它和书里每章的 **⚠️ Common Mistakes** 一一呼应。先判断你卡在哪一篇、哪一节。
3. **对照修正** —— 在对应行看"为什么错"和"修正"，照着改就行。如果还不行，再带着最后一行报错去问人或搜索。

> 💡 **Key Insight:** 把"报错 → 章节 → 修正"练成肌肉记忆，你的调试速度会甩开大多数初学者。本书第 9 章（调试与调试思维）会系统教你怎么"读"报错。

## 一、Windows / Mac 各自专属报错

> ⚠️ **Warning:** 下面这些坑**只在特定系统出现**，书里第 0 章专门讲过。如果你装环境时出了问题，先看这里。

| 系统 | 专属坑 | 典型表现 | 为什么错 | 修正 |
|------|--------|----------|----------|------|
| 🪟 Windows | 安装时没勾 PATH | 敲 `python` 报"不是内部或外部命令" | 系统找不到 python 程序 | 重装时务必勾选 **"Add python.exe to PATH"**（见 §0.1） |
| 🪟 Windows | 误装微软商店版 Python | 从商店点装的 Python 不在 PATH、行为诡异 | 商店版与官方版不一致、易冲突 | 一律用 `python.org` 官方安装包 |
| 🪟 Windows | 把文件放中文/空格路径 | `C:\用户\我的代码\hello.py` 解析报错 | 路径里有中文或空格，命令行解析出错 | 放纯英文短路径，如 `C:\python_practice` |
| 🍎 macOS | 用 `python` 而非 `python3` | `python` 指向老掉牙的 Python 2 | Mac 上 `python` 常指向淘汰的 Python 2 | 验证/运行一律用 `python3`（见 §0.2） |
| 🍎 macOS | 动系统自带 Python | 改 `/usr/bin/python` 导致系统异常 | 那是系统自己用的，动不得 | 装独立的 Python 3，绝不碰系统那份 |

> 💡 **Pro Tip:** 装完无论哪个系统，都做"三连验证"——`python --version`（Mac 用 `python3`）→ 进交互看到 `>>>` → 打印 `你好，Python！`。三步全过，环境就稳了。

## 二、全书各章常见误区总表

> 📝 **Note:** 第〇章、第一章已完稿，下表这两章的条目**直接取自原章**；第二章起的条目按全书大纲预设，待对应章节定稿后由主编核对微调，但内容都对应各章既定主题，可放心参考。

| 章节 | 误区 | 示例 | 为什么错 | 修正 |
|------|------|------|----------|------|
| §0.1 Windows 安装 | 忘勾 PATH | 装完敲 `python` 报"不是内部命令" | 系统找不到 python 程序 | 重装时勾 "Add python.exe to PATH" |
| §0.2 macOS 安装 | 用 `python` | `python` 指向老 Python 2 | 版本老、语法不兼容 | 一律用 `python3` |
| §1.1 第一行 print | 中文引号 | `print("你好")` | Python 只认英文 `" "` | 切换输入法，用英文引号 |
| §1.1 第一行 print | 少了括号 | `print "你好"` | 现代 Python 必须带 `()` | 写成 `print("你好")` |
| §1.2 海龟画图 | 漏写 import | `turtle.Turtle()` 报红 | 没"请进"工具就用 | 开头加 `import turtle` |
| §1.2 海龟画图 | 转角算错 | 正方形用 `right(45)` | 转不够，图形不闭合 | 正方形用 `90`、三角形用 `120` |
| §2.1 变量与赋值 | `=` 当 `==` 用 | `if x = 5:` 报错 | `=` 是赋值不是比较 | 比较用 `if x == 5:` |
| §2.1 变量与赋值 | 用前没赋值 | `print(y)` 前没给 y 赋值 | 变量不存在 | 先 `y = 某值` 再使用 |
| §2.2 数据类型 | 以为类型固定 | 觉得 a 是数字就不能存文字 | Python 动态类型，a 可变 | 放心重新赋值 `a = "hi"` |
| §2.3 类型转换 | int 转小数串 | `int("3.5")` 报错 | 字符串含小数点不能直接转 int | 先 `int(float("3.5"))` |
| §3.1 字符串基础 | 中文引号 | `s = "你好"` | 中文引号被当普通文字 | 用英文引号 |
| §3.2 索引与切片 | 索引越界 | 短串取 `s[10]` | 超出长度 → IndexError | 先确认长度 `len(s)` |
| §3.2 索引与切片 | 切片方向搞反 | `s[3:1]` 得到空串 | 起点大于终点需写负步长 | 用 `s[1:3]` 或 `s[3:1:-1]` |
| §3.4 格式化 | 漏了 f | `f"x={x}"` 写成 `"x={x}"` | 少了 f，花括号原样输出 | 字符串前加 `f` |
| §4.1 算术运算 | 整数除法误解 | `7 / 2` 得 `3.5` 而非 3 | `/` 就是真除法 | 想取整用 `//` |
| §4.3 逻辑运算 | 写成 && / \|\| | `x && y` 报错 | Python 用 `and`/`or` | 改成 `x and y` |
| §4.4 优先级 | 不加括号 | `not x == 5` 含义模糊 | `not` 优先级易踩坑 | 写成 `not (x == 5)` |
| §5.1 input 输入 | 忘了是字符串 | `input() + 1` 报错 | input 返回 str | 用 `int(input())` 转换 |
| §5.2 输入转换 | 转非法内容 | `int("abc")` 报 ValueError | 字符串不是数字 | 先校验或 `try/except`（第 9 章） |
| §5.3 输出 | 字符串拼数字 | `"分：" + score` 报错 | 不同类型不能直接 `+` | 用 f-string：`f"分：{score}"` |
| §6.1 条件判断 | 多个独立 if | 用三个 `if` 而非 `elif` | 条件可能重复执行 | 互斥分支用 `if / elif / else` |
| §6.1 条件判断 | 漏冒号 | `if x > 0` 报错 | 行尾必须 `:` | 补上 `:` |
| §6.3 布尔逻辑 | 啰嗦写法 | `if x == True:` | 多余比较 | 直接 `if x:` |
| §7.1 while 循环 | 条件写错 | 循环体一次都不跑 | 初始条件就不满足 | 检查进入条件 |
| §7.2 死循环 | 忘更新变量 | `while x < 10:` 里不改 x | 条件永远真 | 循环内更新 `x`（如 `x += 1`） |
| §7.3 累加器 | 初始值忘设 | `total = total + 1` 前没 `total=0` | total 未定义 | 先 `total = 0` |
| §8.1 for 与 range | 误以为含末值 | `range(5)` 是 0–4 不是 1–5 | range 左闭右开 | 想要 1–5 写 `range(1, 6)` |
| §8.2 遍历列表 | 遍历中改长度 | 循环里 `list.remove` | 索引错乱漏元素 | 遍历副本或倒序删 |
| §8.3 嵌套循环 | 变量名撞车 | 两层都用 `i` | 内层覆盖外层 | 内外用不同名（如 i, j） |
| §9.1 读报错 | 不看最后一行 | 只盯第一屏红字 | 真正错误在末尾 | 直接滚到最后一行看类型 |
| §9.3 边界情况 | 没处理空/零 | 空列表或 n=0 时崩 | 漏了边界分支 | 单独处理空、0、1 等边界 |
| §10.1 列表索引 | 忘了从 0 开始 | 取最后一个写 `lst[len(lst)]` | 最大下标是 len-1 | 用 `lst[-1]` 或 `len(lst)-1` |
| §10.2 列表增改 | 共享引用 | `b = a` 后改 b 也改了 a | 这是引用不是拷贝 | 用 `b = a.copy()` |
| §10.3 遍历删除 | 边遍历边删 | `for x in lst: lst.remove(x)` | 索引错位 | 用列表推导或倒序 |
| §10.4 切片 | 含头不含尾 | `lst[1:3]` 只有两个元素 | 切片右端不包含 | 记牢"左闭右开" |
| §11.1 元组 | 想改元组 | `t[0] = 1` 报 TypeError | 元组不可变 | 改用列表，或新建元组 |
| §11.2 集合 | 当列表用索引 | `s[0]` 报错 | 集合无序无下标 | 集合用于去重/判存在，不索引 |
| §11.2 集合 | `{}` 是字典 | `s = {}` 得到 dict | 空集合要 `set()` | 用 `set()` 建空集合 |
| §12.2 字典取值 | 访问不存在的键 | `d["age"]` 键不存在 → KeyError | 键不在字典里 | 用 `d.get("age", 默认值)` |
| §12.3 字典遍历 | 忘了默认是 key | `for k in d:` 拿到的是键 | 默认遍历键 | 要值用 `d.values()`，要键值用 `d.items()` |
| §13.1 嵌套列表 | 行列写反 | `matrix[i][j]` 写成 `[j][i]` | 行、列顺序弄混 | 统一约定"先行后列" |
| §13.2 嵌套字典 | 深层取值链断 | `user["addr"]["city"]` 中间缺键 | 某层键不存在 | 用 `.get` 逐层兜底 |
| §14.2 返回值 | 以为自动返回 | 函数没 `return` 却期待结果 | 没 return 得到 `None` | 明确写 `return 结果` |
| §14.2 默认参数 | 可变默认值 | `def f(x=[]):` 多次调用共享 | 默认列表被复用 | 用 `x=None` 再内部初始化 |
| §15.1 作用域 | 局部改全局 | 函数内改全局变量报 UnboundLocalError | 需声明 `global` | 函数内用 `global x` 或传参返回 |
| §15.2 递归 | 无基线条件 | 递归永远不停止 → 栈溢出 | 缺终止条件 | 先写基线（base case） |
| §16.1 导入 | `from x import *` | 名字被大量覆盖 | 污染命名空间 | 用 `import x` 或具体 `from x import y` |
| §16.3 自写模块 | 不懂 `__main__` | 导入时自动跑测试代码 | 没隔离执行入口 | 用 `if __name__ == "__main__":` |
| §17.1 复杂度直觉 | 只看行数 | 以为行少就一定快 | 快慢看随 n 的增长 | 关注"数据翻倍时时间怎么变" |
| §18.2 二分查找 | 忘记先排序 | 对无序数组二分出错 | 二分要求有序 | 先 `sort()` 再二分 |
| §18.2 二分查找 | 边界更新错 | `lo`/`hi` 写错导致死循环/漏 | 中点取舍不一致 | 固定写法：取不到时 `hi=mid` 或 `lo=mid+1` |
| §19.1 冒泡排序 | 内外层范围错 | 多比一轮或漏比 | 范围算错 | 外层 n-1、内层 n-1-i |
| §20.1 递归 | 参数没缩小 | 递归规模不变 → 无限循环 | 每次要接近基线 | 递归调用传更小的子问题 |
| §21.1 栈与队列 | 错用 list | 用 `pop(0)` 当队列（很慢） | 头部删除是 O(n) | 队列用 `collections.deque` |
| §22.1 贪心 | 想当然贪 | 某些问题贪心会错（如特定找零） | 贪心需证明正确 | 先想反例，不行换搜索/DP |
| §22.2 模拟 | 漏边界状态 | 时间步/状态更新顺序错 | 模拟细节没 cover 全 | 列清单逐项检查边界 |
| §23 文字冒险 | 状态管理乱 | 用一堆散变量记进度 | 难维护易错 | 用字典 `state = {...}` 集中管理 |
| §24 数据分析 | 忘转类型就算 | 读出的数字当字符串相加 | CSV 读出都是 str | 先 `int()`/`float()` 转换 |
| §25 算法擂台 | 暴力超时 | O(n²) 在大数据挂 | 没考虑规模 | 想二分 / 前缀和 / 哈希优化 |
| §26 下一步 | 只收藏不练 | 囤教程却不写代码 | 看会≠写会 | 每天动手写，参加竞赛练手 |

> 💡 **Key Insight:** 注意一个反复出现的"老朋友"——**索引从 0 开始、range 左闭右开、切片含头不含尾**。这条规则在列表、字符串、循环里处处用到，把它刻进脑子，能少踩一半坑。

## 三、几个"高频中的高频"

如果时间只够记住三条，请记住这三处最常被卡住的地方：

1. **`=` 是赋值，`==` 是比较**（§2.1 / §4.2）—— 这是初学者第一杀手。
2. **字符串、input 结果都是"文本"，算数前先 `int()`/`float()` 转换**（§2.3 / §5.2）。
3. **循环/递归一定要让"问题规模变小"**（§7.2 / §15.2 / §20.1）—— 否则不是死循环就是栈溢出。
