# 术语表（Glossary）

> 随写作进度持续补充。术语按拼音/字母排序，便于检索。

---

## B

**编程（Programming）** — 用编程语言告诉计算机"一步步做什么"的过程。本书用 Python 这门语言来学它。

**编写代码 / 写代码（Coding）** — 把想法翻译成编程语言里具体指令的动作。

## C

**抽象（Abstraction）** — 计算思维的核心一步：抓住问题的关键、忽略无关细节，用更简单的模型来表示复杂事物。

**常量（Constant）** — 一旦设定就不再改变的值（本书早期以"约定全大写"简要介绍，深入在第四篇）。

## D

**代码（Code）** — 用编程语言写出来的、计算机能理解并执行的指令文本。

## J

**解释器（Interpreter）** — 把 Python 代码一行行"翻译"成计算机能执行动作的程序。你写的 `.py` 文件就是交给它运行的。

**计算思维（Computational Thinking）** — 像计算机科学家一样思考的能力：把大问题拆小、找规律、抽象、设计步骤、评估效果。本书双引擎之一。

## P

**Python** — 一门语法接近自然语言、可读性强的编程语言。门槛低、天花板高，是本书的主角。

**PATH（环境变量）** — 操作系统用来查找可执行程序的"路径列表"。安装 Python 时勾选"Add to PATH"，才能让终端在任何目录直接敲 `python` 找到它。

## Z

**终端 / 命令行（Terminal / Shell）** — 一个靠输入文字命令来操作电脑的窗口（Windows 的 PowerShell、macOS 的"终端"）。本书第0章会带你认识它。

**算法（Algorithm）** — 解决某类问题的清晰、有限的步骤集合。本书第五篇专门启蒙它。

**IDE（集成开发环境，如 VS Code）** — 把写代码、运行、调试、报错提示集成在一起的软件，比纯记事本更适合编程。
